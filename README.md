# 🎖️ RankKursant

Веб-приложение для учёта и отображения рейтинга курсантов по дисциплине.

## 📋 Функционал

### Два режима просмотра:

**Рейтинг взвода:**
- Просмотр рейтинга курсантов в выбранном взводе
- Детализация по категориям баллов
- Выбор взвода через выпадающий список

**Рейтинг потока:**
- Общий рейтинг всех курсантов по всем взводам
- Отображение взвода для каждого курсанта
- Сравнение между взводами

### Категории баллов:
- Оценки на занятии (макс. 50 баллов)
- Самостоятельная работа (макс. 30 баллов)
- Дополнительные задания (макс. 20 баллов)
- Написание статей (макс. 15 баллов)

**Максимум: 115 баллов**
