# 🎖️ RankKursant

**Веб-приложение для учёта и отображения рейтинга курсантов по дисциплине.**

Преподаватель выставляет баллы за различные виды активности, курсанты видят свой рейтинг в группе и общий рейтинг по всем группам.

---

## 📋 Функционал

### Для преподавателя:
- 📊 **Сводка** — обзор по всем группам, топ-10, отстающие курсанты
- 👥 **Группы** — рейтинг конкретной группы с детализацией по категориям
- 🎓 **Карточка курсанта** — все баллы + форма добавления нового балла
- ⚙️ **Настройки** — управление категориями и лимитами баллов

### Для курсанта:
- 🏆 **Мой рейтинг** — позиция в группе + детализация своих баллов
- 📈 **Общий рейтинг** — рейтинг по всем группам (ФИО + сумма)

### Ключевые фичи:
- ✅ Таблица рейтинга с сортировкой по столбцам
- ✅ Цветовая индикация: топ-3 (🥇🥈🥉), отстающие (красный)
- ✅ Модальное окно для быстрого добавления балла
- ✅ Фильтрация по группе и категории
- ✅ Поиск курсанта по ФИО
- ✅ Skeleton-загрузки
- ✅ Toast-уведомления
- ✅ Mobile-first дизайн

## 🏗️ Архитектура (MVP → Production)

### Текущий стек (Frontend MVP):
- **React 18** + **TypeScript**
- **Vite** — сборщик
- **Tailwind CSS 4** — стилизация
- **React Router** — маршрутизация
- **localStorage** — хранение данных (замена бэкенду)
- **lucide-react** — иконки

### Production стек (ШАГ 2+):
- **Next.js 14** — фреймворк
- **Prisma** — ORM
- **PostgreSQL** — база данных
- **NextAuth** — аутентификация
- **Server Actions** — CRUD операции
