# 🎖️ RankKursant

Веб-приложение для учёта и отображения рейтинга курсантов по дисциплине.

## 📋 Функционал

### Два режима просмотра:

**Рейтинг взвода:**
- Просмотр рейтинга курсантов в выбранном взводе
- Детализация по категориям баллов
- Выбор взвода через выпадающий список

**Рейтинг потока:**
- Общий рейтинг всех курсантов по всем взводам
- Отображение взвода для каждого курсанта
- Сравнение между взводами

### Категории баллов:
- Оценки на занятии
- Самостоятельная работа
- Дополнительные задания
- Написание статей

**Максимум баллов неограничен** - каждый курсант может набрать любое количество баллов.

## 🗄️ База данных

Все данные о курсантах и баллах хранятся в отдельном файле:
- `src/data/database.ts` - содержит информацию о группах, курсантах и их баллах

Приложение включает тестовые данные:
- 2 взвода (ВУ-201, ВУ-202)
- 10 курсантов (5 в каждом взводе)
